# 首次配置与使用引导

## 这项 Skill 适合谁

培训/课程运营者、班主任、社群助教、项目协调者，以及需要把聊天里的申请表、作业、证明材料或反馈集中归档并跟踪提交状态的人。它提供工作流，不会自带微信/飞书账号、消息访问权限、后台服务或云存储。

## 选择要启用的模块

开始前让用户选择或从明确请求中推断模块；可以单独使用，也可以组合：

| 模块 | 用途 | 至少需要的信息 |
|---|---|---|
| 微信读取 | 从私聊/群聊发现附件、链接或指定关键词 | 可用的微信 CLI/连接器；要查的账号、会话和时间范围 |
| 名单匹配 | 用正式姓名、昵称或编号识别提交人 | 名单文件/表格链接、序号/姓名/别名列；有无未编号成员 |
| 飞书归档 | 把附件或链接页放入云盘文件夹 | 目标文件夹或知识库位置、可用飞书身份 |
| 索引与统计 | 列出已交/待交、直达每人文档 | 索引放置位置、名单统计口径、链接格式 |
| 卡片提醒 | 成功新增/更新后向指定会话发送摘要 | 接收人或会话、机器人/用户身份、内容字段 |
| 定时扫描 | 周期性检查增量消息 | 间隔、时区、起始点、异常处理、通知策略 |

## 推荐的引导问题

如果当前会话/电脑/已连接应用中查不到答案，一次性问清必要项，不要问用户重复提供已有信息：

1. “你要处理哪个微信账号、哪些私聊/群聊，时间范围从什么时候开始？”
2. “名单在哪里？哪列是正式姓名、哪列是昵称/别名？名单编号是否为统计口径？”
3. “归档到哪个飞书文件夹？命名想采用什么格式？”
4. “是否要维护索引？索引需要显示哪些统计和未交名单？”
5. “是否要定时扫描和发卡片？频率、时区、收件人/会话是什么？”

用户说“都处理”且必要信息可从已有任务/本机配置读到时，直接继续。账号登录、读取私聊/群聊、云端存储和对外发送均受各自授权范围约束；不要把安装 Skill 等同于完成这些授权。

## 环境检查

- 查找已安装的微信读取工具、插件或本机 skill。先读该工具的本机说明和 `--help`，确认可列会话、按时间取消息、区分附件类型并定位下载文件。
- 查找飞书/Lark 文档与云盘工具。按当前 skill 获取文件夹清单、创建/导入文档、移动文档、读写索引和发送卡片的要求操作。
- 记录可复用的非敏感配置：工作目录、CLI 路径、数据目录（只记路径）、名单位置、归档位置、时区、间隔、收件人标识。令牌、数据库解密密钥或 cookie 不进入配置模板或版本控制。
- 若工具不存在或凭证失效，报告精确缺口及用户需要完成的登录/授权步骤；继续任何可独立完成的只读盘点。

## 示例请求

- “把这个群里本周收到的报名表按名单姓名存到飞书文件夹，只给我一个清单，不发通知。”
- “把最近收到的作业整理到现有学生文件夹，每人只留最新版本，更新索引。”
- “每小时查指定群的新申请；成功归档后给我发一张人数卡片。工作日 9:00–18:00 执行。”
- “我已经有本地 DOCX 文件，帮我做飞书归档和索引，不要读取微信。”
