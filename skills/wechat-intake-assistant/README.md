# 微信资料归档助手

**WeChat Intake Assistant** 是一个可选模块化的 Codex Skill，适用于培训运营、班主任、社群助教、项目协调者等需要整理聊天文件并追踪提交状态的人。

它指导 Codex 把聊天中的文件/链接匹配到名单成员，归档至飞书，维护已交/待交索引，并可选发送进度卡片或创建周期扫描任务。微信读取、飞书写入、通知和定时任务可分别启用；安装 Skill 本身不会自动获得账号权限，也不会自动扫描或发送。

## 模块

- 微信私聊/群聊增量读取
- 按正式姓名、序号、昵称/别名匹配
- 飞书云盘文档归档与最新版本去重
- 已交/待交统计及一键直达索引
- 可选飞书卡片通知
- 可选周期扫描自动化

## 使用前准备

按需要准备以下项目：

1. **微信读取**：本机已登录的微信及可用的读取工具（例如已安装并初始化的 `wechat-cli`），并确认要读取的账号、私聊/群聊和时间范围。
2. **名单匹配**：名单文件或飞书表格链接，注明编号、正式姓名、别名所在列。没有名单时可以按发送者归档，但不会推测序号。
3. **飞书归档**：已登录的飞书/Lark CLI 或连接器，以及目标文件夹。需要卡片通知时还要确认目标会话/接收人和可用发送身份。
4. **周期扫描（可选）**：可用自动化/调度工具、扫描间隔、时区、首次扫描基线和失败通知策略。

如果使用者没有准备好某项依赖，可仅启用其余模块。例如“只根据我上传的 DOCX 建索引”不需要微信读取；“只检查微信新消息并列清单”不需要飞书写入。

## 安装到 Codex

```powershell
git clone https://github.com/siyuesunsx-siyue/codex-lark-starter.git
Copy-Item -Recurse .\codex-lark-starter\skills\wechat-intake-assistant `
  "$HOME\.codex\skills\wechat-intake-assistant"
```

重新加载 Codex 后可直接描述任务，或显式调用 `$wechat-intake-assistant`。其他支持 Agent Skills 目录格式的工具，可将该文件夹放到其 skills 目录；具体加载方式以该工具说明为准。

## 使用示例

```text
帮我查看微信“报名群”从昨天到现在的新报名表，按我给的名单姓名保存到飞书“春季班报名”，更新索引。先不设置定时任务，也不要发消息。
```

```text
每30分钟检查指定微信账号的私聊和“课程群”，发现新课前信息表后按名单编号和姓名归档，更新已交/未交索引，并向我的飞书个人会话发送人数卡片。首次扫描以当前归档为基线。
```

## 隐私与限制

本 Skill 不内含任何微信/飞书登录信息、用户数据、附件或密钥。它不会绕过登录限制，也不保证本机离线时定时任务仍会执行。飞书 API 接收消息不能证明手机系统通知已弹出。使用者应遵守其组织的隐私、数据保留与平台条款要求。
