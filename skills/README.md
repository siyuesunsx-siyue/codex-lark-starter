# Reusable Codex Skills

This repository includes task-focused skills that can be installed independently.

## 微信资料归档助手 / WeChat Intake Assistant

Collect files and links from WeChat, match them against a roster, archive them in Feishu/Lark, maintain a linked submission index, and optionally send progress cards or schedule recurring scans.

- [Open the skill](wechat-intake-assistant/)
- [Read the usage and setup guide](wechat-intake-assistant/README.md)
- [Read the skill instructions](wechat-intake-assistant/SKILL.md)

To install it, clone this repository and copy `skills/wechat-intake-assistant` into your Codex skills directory (usually `~/.codex/skills/wechat-intake-assistant`). For other Agent Skills-compatible clients, use that client's documented skills directory.

The skill does not contain account credentials or user data. WeChat access, Feishu access, scheduled scans, and notifications are optional and require their own local tools and authorization.
